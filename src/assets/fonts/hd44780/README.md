# HD44780U A00 CGROM (Display Module 2)

Bitmap glyphs for the JHD1313 LCD canvas, derived from the **Display Module 2**
BDF in [dse/display-module-fonts](https://github.com/dse/display-module-fonts)
(HD44780U character ROM code A00 — Latin + Katakana).

The canvas paints these as discrete 5×8 dots (`src/components/hd44780Glyphs.ts`)
so characters stay crisp (no TrueType antialiasing).
