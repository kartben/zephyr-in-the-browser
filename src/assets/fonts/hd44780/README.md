# Display Module 2 (HD44780U A00)

Pixel font matching the Hitachi HD44780U character ROM code **A00** — the
5×8 Latin + Katakana map used by Grove / Jinghua JHD1313 RGB LCDs.

Source: [dse/display-module-fonts](https://github.com/dse/display-module-fonts)
(`dist/ttf/display-module-2.ttf`).
